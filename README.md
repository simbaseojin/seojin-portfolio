# 이서진 Product Leader 포트폴리오

인터랙티브 경력 포트폴리오 (정적 사이트, 빌드 도구 없음).

## 콘텐츠 수정
모든 내용은 [`content.json`](content.json) 한 파일에 있습니다. 자세한 방법은 [EDITING.md](EDITING.md) 참고.

## 구조
- `index.html` / `styles.css` / `app.js` — 디자인 + 렌더링
- `content.json` — 모든 콘텐츠 (여기만 수정)
- `assets/` — 이미지
- `EDITING.md` — 편집 가이드

## 배포
GitHub Pages로 자동 배포됩니다. `main` 브랜치에 변경을 커밋(푸시)하면 몇 분 뒤 사이트에 반영됩니다.
